# Say_It_Your_Way_Romanian

Romanian language-learning app for dyslexia/ADHD-friendly practice.

## Romanian language governance

All Romanian learner-facing content is governed by **[docs/LANGUAGE_DATA_GOVERNANCE.md](docs/LANGUAGE_DATA_GOVERNANCE.md)**.

Before changing language data, run:

```bash
npm run language:qa
```

AI agents: see **[AGENTS.md](AGENTS.md)**.
